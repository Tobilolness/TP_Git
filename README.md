# Les Gardiens de l'Aube

## Description du projet

Les Gardiens de l'Aube est un site web statique fictif qui présente une équipe de trois super-héros protégeant Nova City. Il comporte une page d'accueil avec le nom de l'équipe, son slogan et sa mission, ainsi qu'une page dédiée aux héros et à leurs pouvoirs.

## Auteurs

Tobias (GitHub : [@Tobilolness](https://github.com/Tobilolness))

## Technologies utilisées

- HTML5 pour la structure des pages
- CSS3 pour la mise en forme, les couleurs, la typographie et l'adaptation aux écrans mobiles
- Google Fonts : Inter et Orbitron

## Structure du projet

```text
TP_Git/
├── index.html   # Page d'accueil
├── heroes.html  # Présentation des trois super-héros
├── style.css    # Styles communs du site
└── README.md    # Documentation du projet
```

## Lancer le site

Ouvrez `index.html` dans un navigateur web. Le lien vers `heroes.html` permet d'accéder aux profils des trois héros. Une connexion Internet est nécessaire pour charger les polices Google Fonts ; des polices de remplacement sont prévues si elles ne sont pas disponibles.
